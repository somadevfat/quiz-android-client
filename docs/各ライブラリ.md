# Androidライブラリ 最新安定版ドキュメント (2024年6月現在)

ご提示いただいたGradleバージョンリストを元に、**現在（2024年6月）**の最新**安定版 (Stable)** バージョンを一つずつ調査し、記載しました。

## ✅ バージョン更新の概要と注意点

* **Kotlin 2.0.0 と Compose Compiler の互換性:** Kotlin `2.0.0` を利用する場合、Jetpack Compose Compilerのバージョンは `1.5.14` が必須です。これらはセットで更新してください。
* **Android Gradle Plugin (AGP):** 最新の安定版は `8.4.1` です。AGP 8.4系には、Gradle 8.4以上が推奨されます。
* **プレリリース版からの更新:** ご提示のリストに含まれていた `beta` や `alpha` 版については、公式にリリースされている最新の安定版を記載しています。例えば、`navigation-compose` は `2.7.7` が現在の安定版です。
* **ライブラリのメジャーバージョン:** `Retrofit` はバージョン `3.0.0` がまだベータ版のため、安定版である `2.11.0` を記載しています。同様に `Coil` は、安定しているCoil 2系の最新版 `2.6.0` を記載します。
